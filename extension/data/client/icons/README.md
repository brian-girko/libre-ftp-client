# icons

File type icons vendored from [vscode-material-icon-theme]
(https://github.com/PKief/vscode-material-icon-theme) — MIT License —
pinned to commit `dd1547babd192e3a307d8acfb2325306b6e89e4d`.

`folder.svg`, `folder-open.svg` and `file.svg` are not checked into the
upstream `icons/` dir (upstream generates them during its build); they are
reproduced here from the upstream generator sources using the default
color `#90a4ae`.

The set is curated: only the icons referenced by `../fs/icons.js` are kept.
Mapping of extensions to icon names lives in `../fs/icons.js`.
